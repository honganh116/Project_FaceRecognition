## Công nghệ sử dụng
- Backend: FastAPI, DeepFace, Python
- Frontend: HTML/JS / React
- Database: PostgreSQL, Vector Database (Qdrant/Milvus), MinIO
- Deploy: Docker, Docker Compose

## Cách chạy dự án
1. Clone repository này về máy.
2. Đổi tên file `.env.example` thành `.env` và điền các thông tin cần thiết.
3. Chạy lệnh: `docker-compose up -d`
